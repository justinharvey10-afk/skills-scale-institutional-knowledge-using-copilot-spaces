# OctoAcme Project Management Docs

## Overview
This README provides quick access and a summary of project management processes used by OctoAcme. It links to all documentation maintained in the docs/ folder, helping team members and stakeholders navigate processes, roles, and practices.

## Project Management Process Summary
OctoAcme uses iterative, customer-first project delivery with clear ownership and data-informed decisions. Core stages: initiation, planning, execution, release, and retrospective. Key roles include Product Manager, Project Manager, Developers, QA, and Stakeholders. Communication includes weekly syncs, standups, stakeholder updates, and use of project boards for workflow tracking.
